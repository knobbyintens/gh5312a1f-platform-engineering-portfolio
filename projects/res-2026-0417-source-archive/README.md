# res-2026-0417-source-archive

Automated archival mirror of research report `RES-2026-0417` — *Delta-Compressed
Bitmap Indexes for Low-Latency Analytics* (Raman, Ito, Alvarez).

This project contains the submitted manuscript source only. The ingest bot
creates one project directory per report; this directory is not an engineering
project and contains no implementation code.

- `paper/references.bib` — bibliography
